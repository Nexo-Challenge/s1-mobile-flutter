# Checklist Mobile — Sprint 1

Fonte: PDF `2TDS Agosto - Marinha 2026 - 1º Semestre V2.pdf`, Mobile 1/9–9/9. Todos os itens estão pendentes.

- [ ] Desenvolver versão funcional em Flutter e Dart, coerente com a solução e conteúdos das aulas.
- [ ] Pelo menos 5 telas justificadas pela jornada; não criar telas apenas para atingir quantidade.
- [ ] Navegação Flutter funcional, avanço/retorno e parâmetros quando necessários.
- [ ] Interface funcional e identidade consistente: cores, tipografia, espaçamento e componentes.
- [ ] Utilizar widgets trabalhados em aula conforme necessidade.
- [ ] Demonstrar alteração dinâmica da interface usando StatefulWidget e setState().
- [ ] Formulário funcional com entrada, campos adequados, validação, envio e resposta ao usuário (ex.: SnackBar/Dialog).
- [ ] Dados mockados permitidos; backend e banco não obrigatórios nesta sprint.
- [ ] README com projeto, integrantes, descrição, parceiro quando aplicável, execução, tecnologias e link de vídeo.
- [ ] Histórico Git incremental, claro e representando evolução real.
- [ ] Vídeo narrado por integrante(s), máximo 5 minutos, YouTube não listado.
- [ ] Vídeo demonstra todas as telas, navegação, formulário, validação, estado e interação.
- [ ] Executar em emulador Android ou dispositivo físico; somente navegador não atende.
- [ ] Confirmar com professor/portal a dispensa de Classroom informada pelo usuário: PDF exige esse destino e prevê penalidade.
- [ ] Confirmar prazo e horário oficiais devido à divergência de datas do PDF.
